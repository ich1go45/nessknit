# nessknit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `nessknit`, a Go command-line tool that merges several Nessus `.nessus` files into one, reproducing the merge rules of the Python script it replaces while keeping memory use flat.

**Architecture:** Two streaming passes. Pass 1 (`internal/index`) reads each input once and records byte offsets of the header, each `ReportHost`, and its `HostProperties`. Pass 2 (`internal/merge`) walks hosts in first-seen order and copies elements from the inputs to the output as raw bytes, holding only one host's finding keys in memory. `cmd/nessknit` wires the passes to flags, a temp-file-then-rename write, a read-back check, and a summary.

**Tech Stack:** Go 1.24 or later, standard library only (`encoding/xml`, `flag`, `crypto/sha256`). Tests use the standard `testing` package. One test shells out to `python3` and is skipped without it.

**Spec:** `docs/superpowers/specs/2026-10-11-nessknit-design.md`. Read it before starting; the merge rules there are numbered and the tests refer to them.

## Where this plan departs from the spec

These are small and deliberate. None changes behaviour the spec promises.

- Two helper packages the spec does not list: `internal/logx` (the leveled stderr logger) and `internal/nessustest` (test-only builders and a parser for comparing merged output).
- Unit tests build their inputs inline with `nessustest` instead of reading files from `testdata/`. Only the parity test uses fixture files, in `testdata/parity/`.
- The summary reports skipped scan-information items (plugin 19506) separately from duplicates.
- A UTF-8 byte order mark at the start of the primary file is accepted and not copied to the output.
- A host that appears twice within one file is merged into a single host, by the same rules as across files.
- The temporary file is `<output>.tmp`, as in the Python script.

## Review Focus

Inputs the spec is silent on that a person will hit. Each has a test in the task named.

1. Flags placed after paths (`nessknit scans/ -o out.nessus`): must work, not treat `-o` as a file. Go's `flag` package stops at the first non-flag argument by default. Task 5, `TestFlagsMayFollowPaths`.
2. The same file reached twice (named explicitly and again through its directory): merged once, not flagged as all duplicates. Task 2, `TestSameFileGivenTwiceIsListedOnce`.
3. An input that starts with a UTF-8 byte order mark: merged normally, with no mark in the output. Task 1, `TestScanSkipsByteOrderMark`; Task 4, `TestByteOrderMarkIsNotCopied`.
4. The same host name twice inside one file: one host in the output, not two with the same name. Task 4, `TestSameHostTwiceInOneFileIsMerged`.
5. An output path whose directory does not exist or cannot be written: exit `1` with the path in the message, nothing left behind. Task 5, `TestUnwritableOutputFails`.

````go
// Package nessustest builds small .nessus documents for tests and parses
// merged output back into plain values that tests can compare.
package nessustest

import (
	"encoding/xml"
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"testing"
)

// File returns a complete .nessus document. hosts are the strings
// returned by Host.
func File(policy, report string, hosts ...string) string {
	return `<?xml version="1.0" ?>
<NessusClientData_v2>
<Policy><policyName>` + policy + `</policyName></Policy>
<Report name="` + report + `" xmlns:cm="http://www.nessus.org/cm">
` + strings.Join(hosts, "") + `</Report>
</NessusClientData_v2>
`
}

// Host returns a ReportHost element. children are the strings returned
// by Props and Item, in the order they should appear.
func Host(name string, children ...string) string {
	return `<ReportHost name="` + name + `">` + "\n" + strings.Join(children, "") + "</ReportHost>\n"
}

// Props returns a HostProperties element holding tags built with Tag.
func Props(tags ...string) string {
	return "<HostProperties>\n" + strings.Join(tags, "") + "</HostProperties>\n"
}

// Tag returns one HostProperties tag.
func Tag(name, value string) string {
	return fmt.Sprintf("<tag name=\"%s\">%s</tag>\n", name, value)
}

// Item returns a ReportItem. output is written as-is, so it may contain
// entities or a CDATA section.
func Item(plugin, port, proto, severity, output string) string {
	return fmt.Sprintf("<ReportItem port=\"%s\" svc_name=\"general\" protocol=\"%s\" severity=\"%s\" pluginID=\"%s\" pluginName=\"plugin %s\" pluginFamily=\"General\">\n<description>d</description>\n<plugin_output>%s</plugin_output>\n</ReportItem>\n",
		port, proto, severity, plugin, plugin, output)
}

// Write stores content as dir/name and returns the path.
func Write(t testing.TB, dir, name, content string) string {
	t.Helper()
	path := filepath.Join(dir, name)
	if err := os.WriteFile(path, []byte(content), 0o644); err != nil {
		t.Fatal(err)
	}
	return path
}

// Doc is a parsed .nessus file reduced to what the merge rules govern.
type Doc struct {
	Policy     string
	ReportName string
	Hosts      []HostData
}

type HostData struct {
	Name  string
	Tags  []TagData
	Items []ItemData
}

type TagData struct{ Name, Value string }

// ItemData holds a finding's identity. Output has surrounding
// whitespace removed.
type ItemData struct{ Plugin, Port, Proto, Severity, Output string }

type xFile struct {
	XMLName xml.Name `xml:"NessusClientData_v2"`
	Policy  struct {
		Name string `xml:"policyName"`
	} `xml:"Policy"`
	Report struct {
		Name  string  `xml:"name,attr"`
		Hosts []xHost `xml:"ReportHost"`
	} `xml:"Report"`
}

type xHost struct {
	Name string `xml:"name,attr"`
	Tags []struct {
		Name  string `xml:"name,attr"`
		Value string `xml:",chardata"`
	} `xml:"HostProperties>tag"`
	Items []struct {
		Plugin   string `xml:"pluginID,attr"`
		Port     string `xml:"port,attr"`
		Proto    string `xml:"protocol,attr"`
		Severity string `xml:"severity,attr"`
		Output   string `xml:"plugin_output"`
	} `xml:"ReportItem"`
}

// Parse reads a .nessus file. It fails the test if the file is not
// well-formed.
func Parse(t testing.TB, path string) Doc {
	t.Helper()
	data, err := os.ReadFile(path)
	if err != nil {
		t.Fatal(err)
	}
	return ParseBytes(t, data)
}

// ParseBytes is Parse for content already in memory.
func ParseBytes(t testing.TB, data []byte) Doc {
	t.Helper()
	var x xFile
	if err := xml.Unmarshal(data, &x); err != nil {
		t.Fatalf("output is not well-formed: %v", err)
	}
	doc := Doc{Policy: x.Policy.Name, ReportName: x.Report.Name}
	for _, h := range x.Report.Hosts {
		hd := HostData{Name: h.Name}
		for _, tg := range h.Tags {
			hd.Tags = append(hd.Tags, TagData{tg.Name, tg.Value})
		}
		for _, it := range h.Items {
			hd.Items = append(hd.Items, ItemData{it.Plugin, it.Port, it.Proto, it.Severity, strings.TrimSpace(it.Output)})
		}
		doc.Hosts = append(doc.Hosts, hd)
	}
	return doc
}
````

````go
package index

import (
	"strings"
	"testing"

	nt "github.com/ich1go45/nessknit/internal/nessustest"

// The whole design rests on this: slicing the source at the offsets
// Scan records must yield exactly the elements they claim to locate.
// The policy name is non-ASCII so that a rune/byte mix-up would show.
func TestScanOffsetsSliceToExactElements(t *testing.T) {
	src := nt.File("pölicy ✓", "r1",
		nt.Host("10.0.0.1",
			nt.Props(nt.Tag("HOST_END", "x")),
			nt.Item("19506", "0", "tcp", "0", "a &lt; b"),
			nt.Item("10267", "22", "tcp", "2", "ssh"),
		),
		`<ReportHost name="empty"/>`+"\n",
	)
	f, err := Scan(nt.Write(t, t.TempDir(), "a.nessus", src))
	if err != nil {
		t.Fatal(err)
	}
	slice := func(r Range) string { return src[r.Start:r.End] }

	if got, want := slice(f.ReportOpen), `<Report name="r1" xmlns:cm="http://www.nessus.org/cm">`; got != want {
		t.Errorf("ReportOpen = %q, want %q", got, want)
	}
	if got := slice(f.ReportName); got != "r1" || !f.HasReportName {
		t.Errorf("ReportName = %q (has=%v), want r1", got, f.HasReportName)
	}
	header := src[f.HeaderStart:f.HeaderEnd]
	if !strings.HasPrefix(header, "<?xml") || !strings.HasSuffix(header, "nessus.org/cm\">\n") {
		t.Errorf("header = %q", header)
	}
	if f.ReportSelfClosed {
		t.Error("ReportSelfClosed = true")
	}

	if len(f.Hosts) != 2 {
		t.Fatalf("got %d hosts, want 2", len(f.Hosts))
	}
	h := f.Hosts[0]
	if got, want := slice(h.Open), `<ReportHost name="10.0.0.1">`; got != want {
		t.Errorf("Open = %q, want %q", got, want)
	}
	if got := slice(h.Range); !strings.HasPrefix(got, `<ReportHost name="10.0.0.1">`) || !strings.HasSuffix(got, "</ReportHost>") || strings.Count(got, "<ReportHost") != 1 {
		t.Errorf("Range = %q", got)
	}
	if got, want := slice(h.Props), nt.Props(nt.Tag("HOST_END", "x")); !h.HasProps || got+"\n" != want {
		t.Errorf("Props = %q, want %q", got, want)
	}
	if h.Name != "10.0.0.1" || h.Items != 2 {
		t.Errorf("Name = %q, Items = %d", h.Name, h.Items)
	}

	e := f.Hosts[1]
	if got, want := slice(e.Range), `<ReportHost name="empty"/>`; got != want || e.Open != e.Range {
		t.Errorf("self-closing host: Range = %q, Open = %v, Range = %v", got, e.Open, e.Range)
	}
	if e.HasProps || e.Items != 0 {
		t.Errorf("self-closing host: HasProps = %v, Items = %d", e.HasProps, e.Items)
	}
}
````

````go
// Package index scans a .nessus file once and records where its parts
// sit, as byte offsets, without keeping any of the content in memory.
package index

import (
	"bufio"
	"bytes"
	"encoding/xml"
	"fmt"
	"io"
	"os"
	"time"
)

const rootElement = "NessusClientData_v2"

// Range is a half-open byte range [Start, End) within a file.
type Range struct{ Start, End int64 }

func (r Range) Len() int64 { return r.End - r.Start }

// Host locates one named ReportHost element.
type Host struct {
	Name     string
	Range    Range // the whole element, opening tag to closing tag
	Open     Range // the opening tag only
	Props    Range // the first HostProperties child; valid if HasProps
	HasProps bool
	Items    int // number of ReportItem children
}

// File is the index of one usable .nessus file.
type File struct {
	Path    string
	Size    int64
	ModTime time.Time

	// The header is [HeaderStart, HeaderEnd): everything before the
	// first ReportHost, minus a leading byte order mark. With no hosts
	// it ends at the closing Report tag, or at the end of a
	// self-closing Report tag.
	HeaderStart      int64
	HeaderEnd        int64
	ReportOpen       Range // the opening Report tag
	ReportSelfClosed bool  // the Report tag is written as <Report .../>

	// ReportName is the value of the Report name attribute, without
	// its quotes. If HasReportName is false the range is empty and
	// marks where a name attribute can be inserted.
	ReportName    Range
	HasReportName bool

	Hosts    []Host
	Nameless int // ReportHost elements skipped for having no name
}

// RejectError says why a file cannot be merged.
type RejectError struct {
	Path   string
	Reason string
}

func (e *RejectError) Error() string { return e.Reason }

// Scan reads the file at path once and returns its index. It returns a
// *RejectError if the file is readable but not a usable .nessus file.
func Scan(path string) (*File, error) {
	fh, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer fh.Close()
	st, err := fh.Stat()
	if err != nil {
		return nil, err
	}
	f := &File{Path: path, Size: st.Size(), ModTime: st.ModTime(), HeaderEnd: -1}
	reject := func(format string, a ...any) (*File, error) {
		return nil, &RejectError{Path: path, Reason: fmt.Sprintf(format, a...)}
	}

	var badCharset string
	dec := xml.NewDecoder(bufio.NewReaderSize(fh, 1<<20))
	dec.CharsetReader = func(label string, _ io.Reader) (io.Reader, error) {
		badCharset = label
		return nil, fmt.Errorf("unsupported encoding %q", label)
	}

	var (
		depth               int
		sawRoot, haveReport bool
		inReport, inProps   bool
		cur                 *Host
	)
	for {
		start := dec.InputOffset()
		tok, err := dec.Token()
		if err == io.EOF {
			break
		}
		if err != nil {
			if badCharset != "" {
				return reject("unsupported encoding %q (only UTF-8 is supported)", badCharset)
			}
			return reject("not well-formed XML: %v", err)
		}
		end := dec.InputOffset()

		switch t := tok.(type) {
		case xml.StartElement:
			depth++
			switch {
			case depth == 1 && !sawRoot:
				sawRoot = true
				if t.Name.Local != rootElement {
					return reject("root element is <%s>, expected <%s>", t.Name.Local, rootElement)
				}
			case depth == 2 && !haveReport && t.Name.Local == "Report":
				haveReport, inReport = true, true
				f.ReportOpen = Range{start, end}
			case depth == 3 && inReport && t.Name.Local == "ReportHost":
				if f.HeaderEnd < 0 {
					f.HeaderEnd = start
				}
				if name := attr(t, "name"); name == "" {
					f.Nameless++
				} else {
					cur = &Host{Name: name, Open: Range{start, end}, Range: Range{Start: start}}
				}
			case depth == 4 && cur != nil && t.Name.Local == "HostProperties":
				if !cur.HasProps && !inProps {
					inProps = true
					cur.Props.Start = start
				}
			case depth == 4 && cur != nil && t.Name.Local == "ReportItem":
				cur.Items++
			}
		case xml.EndElement:
			switch {
			case depth == 4 && inProps:
				inProps = false
				cur.HasProps = true
				cur.Props.End = end
			case depth == 3 && cur != nil:
				cur.Range.End = end
				f.Hosts = append(f.Hosts, *cur)
				cur = nil
			case depth == 2 && inReport:
				inReport = false
				if f.HeaderEnd < 0 {
					f.HeaderEnd = start
				}
				f.ReportSelfClosed = end == start
			}
			depth--
		}
	}
	if !sawRoot {
		return reject("empty file or no root element")
	}
	if !haveReport {
		return reject("no <Report> element")
	}

	tag := make([]byte, f.ReportOpen.Len())
	if _, err := fh.ReadAt(tag, f.ReportOpen.Start); err != nil {
		return nil, err
	}
	vs, ve, ok := attrValue(tag, "name")
	f.HasReportName = ok
	f.ReportName = Range{f.ReportOpen.Start + int64(vs), f.ReportOpen.Start + int64(ve)}

	bom := make([]byte, 3)
	if n, _ := fh.ReadAt(bom, 0); n == 3 && bytes.Equal(bom, []byte("\xef\xbb\xbf")) {
		f.HeaderStart = 3
	}
	return f, nil
}

func attr(t xml.StartElement, name string) string {
	for _, a := range t.Attr {
		if a.Name.Space == "" && a.Name.Local == name {
			return a.Value
		}
	}
	return ""
}

// attrValue finds attribute name in the raw bytes of a start tag and
// returns the range of its value, excluding the quotes. If the
// attribute is absent, ok is false and start and end both give the
// offset just after the element name.
func attrValue(tag []byte, name string) (start, end int, ok bool) {
	i := 1 // skip '<'
	for i < len(tag) && !isSpace(tag[i]) && tag[i] != '>' && tag[i] != '/' {
		i++
	}
	nameEnd := i
	for {
		for i < len(tag) && isSpace(tag[i]) {
			i++
		}
		if i >= len(tag) || tag[i] == '>' || tag[i] == '/' {
			return nameEnd, nameEnd, false
		}
		attrStart := i
		for i < len(tag) && tag[i] != '=' && !isSpace(tag[i]) {
			i++
		}
		attrName := string(tag[attrStart:i])
		for i < len(tag) && (isSpace(tag[i]) || tag[i] == '=') {
			i++
		}
		if i >= len(tag) || (tag[i] != '"' && tag[i] != '\'') {
			return nameEnd, nameEnd, false
		}
		quote := tag[i]
		i++
		valueStart := i
		for i < len(tag) && tag[i] != quote {
			i++
		}
		if i >= len(tag) {
			return nameEnd, nameEnd, false
		}
		if attrName == name {
			return valueStart, i, true
		}
		i++
	}
}

func isSpace(b byte) bool { return b == ' ' || b == '\t' || b == '\n' || b == '\r' }
````

How the offsets work: `dec.InputOffset()` read before `dec.Token()` is the byte where the next token starts; read after, it is the byte where that token ends. A self-closing tag yields a start token covering the whole tag and then an end token of zero length, which is how `ReportSelfClosed` is detected.

````go
package index

import (
	"errors"
	"os"
	"path/filepath"
	"strings"
	"testing"

	nt "github.com/ich1go45/nessknit/internal/nessustest"
)

func scan(t *testing.T, src string) (*File, error) {
	t.Helper()
	return Scan(nt.Write(t, t.TempDir(), "in.nessus", src))
}

func mustScan(t *testing.T, src string) *File {
	t.Helper()
	f, err := scan(t, src)
	if err != nil {
		t.Fatal(err)
	}
	return f
}

func TestScanRejects(t *testing.T) {
	good := nt.File("p", "r", nt.Host("h"))
	cases := []struct {
		name, src, reason string
	}{
		{"truncated", good[:len(good)-30], "not well-formed XML"},
````

````go
// Package inputs turns command-line paths into the ordered list of
// .nessus files to merge.
package inputs

import (
	"errors"
	"os"
	"path/filepath"
	"strings"
)

// ErrNoInputs is returned when the paths yield no file to merge.
var ErrNoInputs = errors.New("no .nessus files found")

// Resolve expands paths into files, in the order given. A directory
// contributes the .nessus files directly inside it, sorted by name. A
// file path is taken as it is, whatever its extension. With no paths,
// the current directory is used.
//
// The output file is left out, and a file reached twice is listed
// once. Both checks compare resolved absolute paths with symlinks
// followed. A path that does not exist is an error.
func Resolve(paths []string, output string) ([]string, error) {
	if len(paths) == 0 {
		paths = []string{"."}
	}
	seen := map[string]bool{canonical(output): true}
	var files []string
	add := func(p string) {
		if c := canonical(p); !seen[c] {
			seen[c] = true
			files = append(files, p)
		}
	}
	for _, p := range paths {
		st, err := os.Stat(p)
		if err != nil {
			return nil, err
		}
		if !st.IsDir() {
			add(p)
			continue
		}
		entries, err := os.ReadDir(p) // sorted by file name
		if err != nil {
			return nil, err
		}
		for _, e := range entries {
			if strings.EqualFold(filepath.Ext(e.Name()), ".nessus") {
				full := filepath.Join(p, e.Name())
				if st, err := os.Stat(full); err == nil && !st.IsDir() {
					add(full)
				}
			}
		}
	}
	if len(files) == 0 {
		return nil, ErrNoInputs
	}
	return files, nil
}

// canonical returns an absolute path with symlinks resolved. If the
// file does not exist yet, its directory is resolved instead.
func canonical(p string) string {
	abs, err := filepath.Abs(p)
	if err != nil {
		return filepath.Clean(p)
	}
	if real, err := filepath.EvalSymlinks(abs); err == nil {
		return real
	}
	if dir, err := filepath.EvalSymlinks(filepath.Dir(abs)); err == nil {
		return filepath.Join(dir, filepath.Base(abs))
	}
	return abs
}
````

````go
// Package logx is the small leveled logger nessknit writes to stderr.
package logx

import (
	"fmt"
	"io"
)

// Level selects how much a Logger prints.
type Level int

const (
	Quiet  Level = iota // warnings only
	Normal              // warnings and progress
	Debug               // everything
)

// Logger writes prefixed lines to one writer. A nil *Logger discards
// everything, so callers never need to check for it.
type Logger struct {
	w     io.Writer
	level Level
}

func New(w io.Writer, level Level) *Logger {
	return &Logger{w: w, level: level}
}

// Warnf always prints.
func (l *Logger) Warnf(format string, a ...any) { l.print(Quiet, "[!] ", format, a) }

// Infof prints progress unless the level is Quiet.
func (l *Logger) Infof(format string, a ...any) { l.print(Normal, "[*] ", format, a) }

// Debugf prints only at the Debug level.
func (l *Logger) Debugf(format string, a ...any) { l.print(Debug, "[debug] ", format, a) }

func (l *Logger) print(min Level, prefix, format string, a []any) {
	if l == nil || l.level < min {
		return
	}
	fmt.Fprintf(l.w, prefix+format+"\n", a...)
}
````

````go
// Package summary holds the counts from one merge and renders them.
package summary

import (
	"encoding/json"
	"fmt"
	"io"
	"strings"
)

// FileStats counts what one input file contributed.
type FileStats struct {
	Path            string `json:"path"`
	NewHosts        int    `json:"new_hosts"`
	SeenHosts       int    `json:"seen_hosts"`
	Findings        int    `json:"findings"`
	BySeverity      [5]int `json:"by_severity"` // index 0 (info) to 4 (critical)
	UnknownSeverity int    `json:"unknown_severity"`
	Duplicates      int    `json:"duplicates_dropped"`
	ScanInfoSkipped int    `json:"scan_info_skipped"`
	NamelessHosts   int    `json:"nameless_hosts_skipped"`
}

// CountFinding records one written finding with the given severity
// attribute value.
func (f *FileStats) CountFinding(severity string) {
	f.Findings++
	if len(severity) == 1 && severity[0] >= '0' && severity[0] <= '4' {
		f.BySeverity[severity[0]-'0']++
	} else {
		f.UnknownSeverity++
	}
}

// Skipped names an input that was not merged, and why.
type Skipped struct {
	Path   string `json:"path"`
	Reason string `json:"reason"`
}

// Summary is the result of one run.
type Summary struct {
	Primary  string      `json:"primary"`
	Output   string      `json:"output"`
	DryRun   bool        `json:"dry_run"`
	Hosts    int         `json:"hosts"`
	Findings int         `json:"findings"`
	Files    []FileStats `json:"files"`
	Skipped  []Skipped   `json:"skipped"`
}

// Totals adds up the per-file counts.
func (s *Summary) Totals() FileStats {
	var t FileStats
	for _, f := range s.Files {
		t.NewHosts += f.NewHosts
		t.SeenHosts += f.SeenHosts
		t.Findings += f.Findings
		for i, n := range f.BySeverity {
			t.BySeverity[i] += n
		}
		t.UnknownSeverity += f.UnknownSeverity
		t.Duplicates += f.Duplicates
		t.ScanInfoSkipped += f.ScanInfoSkipped
		t.NamelessHosts += f.NamelessHosts
	}
	return t
}

// WriteJSON writes the summary as one indented JSON object. Empty
// lists are written as [] rather than null.
func (s *Summary) WriteJSON(w io.Writer) error {
	out := *s
	if out.Files == nil {
		out.Files = []FileStats{}
	}
	if out.Skipped == nil {
		out.Skipped = []Skipped{}
	}
	enc := json.NewEncoder(w)
	enc.SetIndent("", "  ")
	return enc.Encode(out)
}

// WriteText writes the summary for a person to read.
func (s *Summary) WriteText(w io.Writer) error {
	var b strings.Builder
	fmt.Fprintf(&b, "Primary : %s\n", s.Primary)
	if s.DryRun {
		b.WriteString("Output  : (dry run, nothing written)\n")
	} else {
		fmt.Fprintf(&b, "Output  : %s\n", s.Output)
	}
	for _, f := range s.Files {
		fmt.Fprintf(&b, "\n%s\n", f.Path)
		fmt.Fprintf(&b, "  hosts    : %d new, %d already seen\n", f.NewHosts, f.SeenHosts)
		writeCounts(&b, f)
	}
	if len(s.Skipped) > 0 {
		fmt.Fprintf(&b, "\nSkipped (%d)\n", len(s.Skipped))
		for _, k := range s.Skipped {
			fmt.Fprintf(&b, "  %s: %s\n", k.Path, k.Reason)
		}
	}
	b.WriteString("\nTotal\n")
	fmt.Fprintf(&b, "  hosts    : %d\n", s.Hosts)
	writeCounts(&b, s.Totals())
	_, err := io.WriteString(w, b.String())
	return err
}

func writeCounts(b *strings.Builder, f FileStats) {
	sev := f.BySeverity
	fmt.Fprintf(b, "  findings : %d (critical %d, high %d, medium %d, low %d, info %d",
		f.Findings, sev[4], sev[3], sev[2], sev[1], sev[0])
	if f.UnknownSeverity > 0 {
		fmt.Fprintf(b, ", unknown %d", f.UnknownSeverity)
	}
	b.WriteString(")\n")
	fmt.Fprintf(b, "  dropped  : %d duplicate, %d scan-info\n", f.Duplicates, f.ScanInfoSkipped)
	if f.NamelessHosts > 0 {
		fmt.Fprintf(b, "  nameless : %d host(s) skipped\n", f.NamelessHosts)
	}
}
````

````go
// Package merge writes one merged .nessus document from indexed input
// files, copying elements as raw bytes and holding one host's finding
// keys in memory at a time.
package merge

import (
	"bufio"
	"bytes"
	"crypto/sha256"
	"encoding/xml"
	"errors"
	"fmt"
	"io"
	"os"
	"strings"

	"github.com/ich1go45/nessknit/internal/index"
	"github.com/ich1go45/nessknit/internal/logx"
	"github.com/ich1go45/nessknit/internal/summary"
)

// scanInfoPlugin is "Nessus Scan Information". It describes a scan, not
// a host, so only a host's first occurrence keeps it.
const scanInfoPlugin = "19506"

// ErrChanged reports that an input file is no longer the file that was
// indexed, so its recorded offsets cannot be trusted.
var ErrChanged = errors.New("file changed after it was indexed")

// Options configures Write.
type Options struct {
	ReportName string       // value for the Report name attribute
	Log        *logx.Logger // may be nil
}

// Write merges files into w. files[0] is the primary: its header is
// used for the output. The returned summary has Primary, Hosts,
// Findings and Files filled in.
func Write(w io.Writer, files []*index.File, opts Options) (*summary.Summary, error) {
	if len(files) == 0 {
		return nil, errors.New("no input files")
	}
	m := &merger{
		w:     w,
		files: files,
		log:   opts.Log,
		sum:   &summary.Summary{Primary: files[0].Path, Files: make([]summary.FileStats, len(files))},
		buf:   make([]byte, 256<<10),
	}
	for i, f := range files {
		m.sum.Files[i].Path = f.Path
		m.sum.Files[i].NamelessHosts = f.Nameless
		fh, err := os.Open(f.Path)
		if err != nil {
			return nil, err
		}
		defer fh.Close()
		st, err := fh.Stat()
		if err != nil {
			return nil, err
		}
		if st.Size() != f.Size || !st.ModTime().Equal(f.ModTime) {
			return nil, fmt.Errorf("%s: %w", f.Path, ErrChanged)
		}
		m.src = append(m.src, fh)
	}

	// Group every host's occurrences, keeping first-seen order.
	var order []string
	occs := map[string][]occurrence{}
	for fi, f := range files {
		for hi := range f.Hosts {
			h := &f.Hosts[hi]
			if _, ok := occs[h.Name]; !ok {
				order = append(order, h.Name)
			}
			occs[h.Name] = append(occs[h.Name], occurrence{file: fi, host: h})
		}
	}

	if err := m.writeHeader(opts.ReportName); err != nil {
		return nil, err
	}
	for _, name := range order {
		if err := m.writeHost(occs[name]); err != nil {
			return nil, err
		}
	}
	if err := m.write("</Report>\n</" + "NessusClientData_v2>\n"); err != nil {
		return nil, err
	}
	return m.sum, nil
}

type occurrence struct {
	file int // index into merger.files
	host *index.Host
}

type merger struct {
	w     io.Writer
	files []*index.File
	src   []*os.File
	log   *logx.Logger
	sum   *summary.Summary
	buf   []byte
}

// itemKey identifies a finding within one host.
type itemKey struct {
	plugin, port, proto string
	output              [sha256.Size]byte // of the trimmed plugin_output text
}

// child is one direct child element of a ReportHost.
type child struct {
	name     string
	rng      index.Range // absolute position in the source file
	key      itemKey     // set for ReportItem
	severity string      // set for ReportItem
}

func (m *merger) write(s string) error {
	_, err := io.WriteString(m.w, s)
	return err
}

// copyRange copies raw bytes from an input file to the output.
func (m *merger) copyRange(file int, r index.Range) error {
	_, err := io.CopyBuffer(m.w, io.NewSectionReader(m.src[file], r.Start, r.Len()), m.buf)
	return err
}

func (m *merger) read(file int, r index.Range) ([]byte, error) {
	b := make([]byte, r.Len())
	if _, err := m.src[file].ReadAt(b, r.Start); err != nil {
		return nil, fmt.Errorf("%s: %w", m.files[file].Path, err)
	}
	return b, nil
}

// writeHeader copies the primary's header with the report name replaced.
func (m *merger) writeHeader(name string) error {
	p := m.files[0]
	var esc bytes.Buffer
	if err := xml.EscapeText(&esc, []byte(name)); err != nil {
		return err
	}
	if err := m.copyRange(0, index.Range{Start: p.HeaderStart, End: p.ReportName.Start}); err != nil {
		return err
	}
	attr := esc.String()
	if !p.HasReportName {
		attr = ` name="` + attr + `"`
	}
	if err := m.write(attr); err != nil {
		return err
	}
	end := p.HeaderEnd
	if p.ReportSelfClosed {
		end = p.ReportOpen.End - 2 // drop "/>"
	}
	if err := m.copyRange(0, index.Range{Start: p.ReportName.End, End: end}); err != nil {
		return err
	}
	if p.ReportSelfClosed {
		return m.write(">\n")
	}
	return nil
}

// writeHost writes one merged ReportHost from all of its occurrences.
func (m *merger) writeHost(occs []occurrence) error {
	first := occs[0]
	name := first.host.Name
	m.sum.Hosts++
	m.sum.Files[first.file].NewHosts++
	for _, o := range occs[1:] {
		m.sum.Files[o.file].SeenHosts++
	}
	if len(occs) > 1 {
		paths := make([]string, len(occs))
		for i, o := range occs {
			paths[i] = m.files[o.file].Path
		}
		m.log.Debugf("host %q appears in %d blocks: %s", name, len(occs), strings.Join(paths, ", "))
	}

	open, err := m.read(first.file, first.host.Open)
	if err != nil {
		return err
	}
	if bytes.HasSuffix(open, []byte("/>")) {
		open = append(open[:len(open)-2], '>')
	}
	if err := m.write(string(open) + "\n"); err != nil {
		return err
	}

	props, err := m.mergedProps(occs)
	if err != nil {
		return err
	}
	propsWritten := props == nil
	writeProps := func() error {
		propsWritten = true
		return m.write(string(props) + "\n")
	}
	if !propsWritten && !first.host.HasProps {
		// Only a later occurrence has properties: they go first.
		if err := writeProps(); err != nil {
			return err
		}
	}

	seen := map[itemKey]struct{}{}
	copyChild := func(o occurrence, c child) error {
		if err := m.copyRange(o.file, c.rng); err != nil {
			return err
		}
		return m.write("\n")
	}

	err = m.eachChild(first, func(c child) error {
		switch {
		case c.name == "HostProperties" && !propsWritten:
			return writeProps()
		case c.name == "ReportItem":
			seen[c.key] = struct{}{}
			m.count(first.file, c)
		}
		return copyChild(first, c)
	})
	if err != nil {
		return err
	}

	for _, o := range occs[1:] {
		stats := &m.sum.Files[o.file]
		err := m.eachChild(o, func(c child) error {
			if c.name != "ReportItem" {
				return nil
			}
			if c.key.plugin == scanInfoPlugin {
				stats.ScanInfoSkipped++
				m.log.Debugf("skip scan-info host=%q from %s", name, stats.Path)
				return nil
			}
			if _, dup := seen[c.key]; dup {
				stats.Duplicates++
				m.log.Debugf("drop duplicate host=%q plugin=%s port=%s/%s output=%x from %s",
					name, c.key.plugin, c.key.port, c.key.proto, c.key.output[:6], stats.Path)
				return nil
			}
			seen[c.key] = struct{}{}
			m.count(o.file, c)
			return copyChild(o, c)
		})
		if err != nil {
			return err
		}
	}
	return m.write("</ReportHost>\n")
}

func (m *merger) count(file int, c child) {
	m.sum.Findings++
	m.sum.Files[file].CountFinding(c.severity)
}

// eachChild streams one ReportHost occurrence and calls fn for each of
// its direct children, in document order.
func (m *merger) eachChild(o occurrence, fn func(child) error) error {
	h := o.host
	section := io.NewSectionReader(m.src[o.file], h.Range.Start, h.Range.Len())
	dec := xml.NewDecoder(bufio.NewReaderSize(section, 64<<10))

	// plugin_output text is collected only from the first plugin_output
	// child, and only up to its first sub-element.
	const (
		outputPending = iota
		outputReading
		outputDone
	)
	var (
		depth  int
		cur    child
		output bytes.Buffer
		state  int
	)
	for {
		start := dec.InputOffset()
		tok, err := dec.Token()
		if err == io.EOF {
			return nil
		}
		if err != nil {
			return fmt.Errorf("%s: host %q: %w", m.files[o.file].Path, h.Name, err)
		}
		switch t := tok.(type) {
		case xml.StartElement:
			depth++
			switch {
			case depth == 2:
				cur = child{name: t.Name.Local, rng: index.Range{Start: h.Range.Start + start}}
				output.Reset()
				state = outputPending
				if cur.name == "ReportItem" {
					for _, a := range t.Attr {
						if a.Name.Space != "" {
							continue
						}
						switch a.Name.Local {
						case "pluginID":
							cur.key.plugin = a.Value
						case "port":
							cur.key.port = a.Value
						case "protocol":
							cur.key.proto = a.Value
						case "severity":
							cur.severity = a.Value
						}
					}
				}
			case depth == 3 && cur.name == "ReportItem" && t.Name.Local == "plugin_output" && state == outputPending:
				state = outputReading
			case depth > 3 && state == outputReading:
				state = outputDone
			}
		case xml.CharData:
			if depth == 3 && state == outputReading {
				output.Write(t)
			}
		case xml.EndElement:
			if depth == 3 && state == outputReading {
				state = outputDone
			}
			if depth == 2 {
				cur.rng.End = h.Range.Start + dec.InputOffset()
				if cur.name == "ReportItem" {
					cur.key.output = sha256.Sum256(bytes.TrimSpace(output.Bytes()))
				}
				if err := fn(cur); err != nil {
					return err
				}
			}
			depth--
		}
	}
}

// mergedProps builds the HostProperties element for a host. The first
// block found is kept as it is; later blocks add only named tags whose
// name has not been seen. It returns nil if no occurrence has one.
func (m *merger) mergedProps(occs []occurrence) ([]byte, error) {
	var (
		base      []byte
		baseClose int
		extra     [][]byte
	)
	names := map[string]struct{}{}
	for _, o := range occs {
		if !o.host.HasProps {
			continue
		}
		raw, err := m.read(o.file, o.host.Props)
		if err != nil {
			return nil, err
		}
		tags, closeAt, err := propTags(raw)
		if err != nil {
			return nil, fmt.Errorf("%s: host %q: %w", m.files[o.file].Path, o.host.Name, err)
		}
		isBase := base == nil
		if isBase {
			base, baseClose = raw, closeAt
		}
		for _, t := range tags {
			if t.name == "" {
				continue
			}
			if _, ok := names[t.name]; ok {
				continue
			}
			names[t.name] = struct{}{}
			if !isBase {
				extra = append(extra, raw[t.start:t.end])
			}
		}
	}
	if base == nil || len(extra) == 0 {
		return base, nil
	}
	var b bytes.Buffer
	if baseClose < 0 { // <HostProperties/>
		b.Write(base[:len(base)-2])
		b.WriteString(">\n")
	} else {
		b.Write(base[:baseClose])
	}
	for _, e := range extra {
		b.Write(e)
		b.WriteByte('\n')
	}
	b.WriteString("</HostProperties>")
	return b.Bytes(), nil
}

type propTag struct {
	name       string
	start, end int
}

// propTags lists the tag children of a raw HostProperties element.
// closeAt is the offset of its closing tag, or -1 if it is self-closing.
func propTags(raw []byte) (tags []propTag, closeAt int, err error) {
	dec := xml.NewDecoder(bytes.NewReader(raw))
	depth := 0
	var cur *propTag
	for {
		start := int(dec.InputOffset())
		tok, err := dec.Token()
		if err == io.EOF {
			return tags, closeAt, nil
		}
		if err != nil {
			return nil, 0, err
		}
		end := int(dec.InputOffset())
		switch t := tok.(type) {
		case xml.StartElement:
			depth++
			if depth == 2 && t.Name.Local == "tag" {
				cur = &propTag{start: start}
				for _, a := range t.Attr {
					if a.Name.Space == "" && a.Name.Local == "name" {
						cur.name = a.Value
					}
				}
			}
		case xml.EndElement:
			if depth == 2 && cur != nil {
				cur.end = end
				tags = append(tags, *cur)
				cur = nil
			}
			if depth == 1 {
				closeAt = start
				if end == start {
					closeAt = -1
				}
			}
			depth--
		}
	}
}
````

Points that are easy to get wrong:

- `eachChild` decodes a section reader that covers exactly one `ReportHost` element, so depth 1 is the host and depth 2 is each child. Offsets from the decoder are relative to the section; add `h.Range.Start`.
- The finding key hashes the decoded text of the first `plugin_output` only, trimmed. `&lt;` and a CDATA `<` are the same text.
- The first occurrence is copied whole, duplicates included. Only later occurrences are filtered.
- `mergedProps` returns the first block untouched when nothing is added, so a host seen once is byte-identical to its source.

````go
// writeBigFile generates a .nessus file of hosts*items findings and
// returns its size in bytes. Odd-numbered items differ between seeds,
// so two files with different seeds overlap by half.
func writeBigFile(t *testing.T, path string, hosts, items, seed int) int64 {
	t.Helper()
	fh, err := os.Create(path)
	if err != nil {
		t.Fatal(err)
	}
	w := bufio.NewWriterSize(fh, 1<<20)
	filler := strings.Repeat("lorem ipsum dolor sit amet ", 12)
	fmt.Fprint(w, "<?xml version=\"1.0\" ?>\n<NessusClientData_v2>\n<Policy><policyName>big</policyName></Policy>\n<Report name=\"big\">\n")
	for h := 0; h < hosts; h++ {
		fmt.Fprintf(w, "<ReportHost name=\"10.%d.%d.%d\">\n<HostProperties>\n<tag name=\"HOST_END\">seed %d</tag>\n</HostProperties>\n", h>>16, h>>8&255, h&255, seed)
		for i := 0; i < items; i++ {
			variant := 0
			if i%2 == 1 {
				variant = seed
			}
			fmt.Fprintf(w, "<ReportItem port=\"%d\" svc_name=\"general\" protocol=\"tcp\" severity=\"%d\" pluginID=\"%d\" pluginName=\"p\">\n<description>%s</description>\n<plugin_output>variant %d %s</plugin_output>\n</ReportItem>\n",
				i, i%5, 10000+i, filler, variant, filler)
		}
		fmt.Fprint(w, "</ReportHost>\n")
	}
	fmt.Fprint(w, "</Report>\n</NessusClientData_v2>\n")
	if err := w.Flush(); err != nil {
		t.Fatal(err)
	}
	st, err := fh.Stat()
	if err != nil {
		t.Fatal(err)
	}
	if err := fh.Close(); err != nil {
		t.Fatal(err)
	}
	return st.Size()
}

// The merge must not hold its inputs in memory: peak heap stays under a
// bound far below the input size.
func TestPeakMemoryDoesNotGrowWithInputSize(t *testing.T) {
	if testing.Short() {
		t.Skip("generates about 150 MB of input")
	}
	const (
		hosts, items = 800, 120
		heapLimit    = 32 << 20
	)
	dir := t.TempDir()
	var total int64
	var files []*index.File
	measure := startHeapSampler()
	for seed := 1; seed <= 2; seed++ {
		path := filepath.Join(dir, fmt.Sprintf("big%d.nessus", seed))
		total += writeBigFile(t, path, hosts, items, seed)
		f, err := index.Scan(path)
		if err != nil {
			t.Fatal(err)
		}
		files = append(files, f)
	}
	sum, err := Write(io.Discard, files, Options{ReportName: "big"})
	if err != nil {
		t.Fatal(err)
	}
	peak := measure()

	if total < 4*heapLimit {
		t.Fatalf("input is only %d MB; too small to prove anything against a %d MB limit", total>>20, heapLimit>>20)
	}
	if wantFindings := hosts*items + hosts*items/2; sum.Hosts != hosts || sum.Findings != wantFindings {
		t.Errorf("hosts %d, findings %d; want %d and %d", sum.Hosts, sum.Findings, hosts, wantFindings)
	}
	if dups := sum.Files[1].Duplicates; dups != hosts*items/2 {
		t.Errorf("duplicates = %d, want %d", dups, hosts*items/2)
	}
	t.Logf("input %d MB, peak heap %d MB", total>>20, peak>>20)
	if peak > heapLimit {
		t.Errorf("peak heap %d MB exceeds the %d MB limit (input was %d MB)", peak>>20, heapLimit>>20, total>>20)
	}
}

// startHeapSampler polls the heap size in the background. The returned
// function stops it and reports the largest value seen.
func startHeapSampler() func() uint64 {
	var (
		peak uint64
		wg   sync.WaitGroup
		done = make(chan struct{})
	)
	sample := func() {
		var ms runtime.MemStats
		runtime.ReadMemStats(&ms)
		if ms.HeapAlloc > peak {
			peak = ms.HeapAlloc
		}
	}
	wg.Add(1)
	go func() {
		defer wg.Done()
		for {
			select {
			case <-done:
				return
			case <-time.After(2 * time.Millisecond):
				sample()
			}
		}
	}()
	return func() uint64 {
		close(done)
		wg.Wait()
		sample()
		return peak
	}
}
````

````go
// nessknit runs the built binary in dir.
func nessknit(t *testing.T, dir string, args ...string) outcome {
	t.Helper()
	var stdout, stderr bytes.Buffer
	cmd := exec.Command(binary, args...)
	cmd.Dir, cmd.Stdout, cmd.Stderr = dir, &stdout, &stderr
	err := cmd.Run()
	var exit *exec.ExitError
	if err != nil && !errors.As(err, &exit) {
		t.Fatal(err)
	}
	return outcome{cmd.ProcessState.ExitCode(), stdout.String(), stderr.String()}
}

	}
````

````go
// Command nessknit merges Nessus scan exports (.nessus files) into one.
package main

import (
	"bufio"
	"errors"
	"flag"
	"fmt"
	"io"
	"os"
	"runtime"
	"runtime/debug"
	"time"

	"github.com/ich1go45/nessknit/internal/index"
	"github.com/ich1go45/nessknit/internal/inputs"
	"github.com/ich1go45/nessknit/internal/logx"
	"github.com/ich1go45/nessknit/internal/merge"
	"github.com/ich1go45/nessknit/internal/summary"
)

const (
	exitOK      = 0
	exitFailed  = 1 // nothing written
	exitUsage   = 2
	exitSkipped = 3 // written, but at least one input was skipped
)

const usage = `nessknit merges Nessus scan exports (.nessus files) into one.

Usage:
  nessknit [flags] <path>...

Each path is a .nessus file or a directory of them (not searched
recursively). Files are merged in the order given; the first usable
one supplies the scan policy. With no path, the current directory is
used.

Flags:
  -o, --output FILE   output file (default "Combined.nessus")
      --name NAME     report name in the merged file (default "Combined Report")
      --dry-run       run the merge and print the summary, write nothing
      --json          print the summary as JSON
  -q, --quiet         suppress progress output
  -d, --debug         print detailed diagnostics
      --version       print the version
  -h, --help          print this help

Exit codes:
  0  merged cleanly
  1  failed, nothing written
  2  bad usage
  3  merged and written, but at least one input file was skipped
`

type options struct {
	output  string
	name    string
	dryRun  bool
	json    bool
	quiet   bool
	debug   bool
	version bool
	paths   []string
}

func main() {
	os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))
}

// parseArgs reads flags and paths. Flags may come before, between or
// after the paths.
func parseArgs(args []string) (options, error) {
	var o options
	fs := flag.NewFlagSet("nessknit", flag.ContinueOnError)
	fs.SetOutput(io.Discard)
	fs.Usage = func() {}
	for _, name := range []string{"o", "output"} {
		fs.StringVar(&o.output, name, "Combined.nessus", "")
	}
	fs.StringVar(&o.name, "name", "Combined Report", "")
	fs.BoolVar(&o.dryRun, "dry-run", false, "")
	fs.BoolVar(&o.json, "json", false, "")
	for _, name := range []string{"q", "quiet"} {
		fs.BoolVar(&o.quiet, name, false, "")
	}
	for _, name := range []string{"d", "debug"} {
		fs.BoolVar(&o.debug, name, false, "")
	}
	fs.BoolVar(&o.version, "version", false, "")

	// The flag package stops at the first non-flag argument, so take
	// one path at a time and resume parsing after it.
	for rest := args; ; {
		if err := fs.Parse(rest); err != nil {
			return o, err
		}
		if fs.NArg() == 0 {
			break
		}
		o.paths = append(o.paths, fs.Arg(0))
		rest = fs.Args()[1:]
	}
	if o.quiet && o.debug {
		return o, errors.New("--quiet and --debug cannot be used together")
	}
	if o.output == "" {
		return o, errors.New("--output needs a file name")
	}
	return o, nil
}

func version() string {
	if bi, ok := debug.ReadBuildInfo(); ok && bi.Main.Version != "" {
		return bi.Main.Version
	}
	return "(devel)"
}

func run(args []string, stdout, stderr io.Writer) int {
	o, err := parseArgs(args)
	if errors.Is(err, flag.ErrHelp) {
		fmt.Fprint(stdout, usage)
		return exitOK
	}
	if err != nil {
		fmt.Fprintf(stderr, "nessknit: %v\nRun 'nessknit --help' for usage.\n", err)
		return exitUsage
	}
	if o.version {
		fmt.Fprintf(stdout, "nessknit %s\n", version())
		return exitOK
	}

	level := logx.Normal
	if o.quiet {
		level = logx.Quiet
	} else if o.debug {
		level = logx.Debug
	}
	log := logx.New(stderr, level)
	fail := func(format string, a ...any) int {
		log.Warnf(format, a...)
		log.Warnf("nothing written")
		return exitFailed
	}

	paths, err := inputs.Resolve(o.paths, o.output)
	if err != nil {
		return fail("%v", err)
	}
	log.Infof("found %d input file(s)", len(paths))

	// Pass 1: index every file.
	started := time.Now()
	var files []*index.File
	var skipped []summary.Skipped
	for _, p := range paths {
		f, err := index.Scan(p)
		if err != nil {
			log.Warnf("skipping %s: %v", p, err)
			skipped = append(skipped, summary.Skipped{Path: p, Reason: err.Error()})
			continue
		}
		log.Infof("indexed %s: %d host(s)", p, len(f.Hosts))
		log.Debugf("%s: %d bytes, header ends at byte %d", p, f.Size, f.HeaderEnd)
		if f.Nameless > 0 {
			log.Warnf("%s: skipped %d ReportHost element(s) with no name", p, f.Nameless)
		}
		files = append(files, f)
	}
	log.Debugf("index pass took %s", time.Since(started).Round(time.Millisecond))
	if len(files) == 0 {
		return fail("none of the %d input file(s) could be used", len(paths))
	}
	log.Infof("primary: %s", files[0].Path)

	// Pass 2: write the merged file.
	started = time.Now()
	opts := merge.Options{ReportName: o.name, Log: log}
	var sum *summary.Summary
	if o.dryRun {
		sum, err = merge.Write(io.Discard, files, opts)
	} else {
		sum, err = writeOutput(o.output, files, opts)
	}
	if err != nil {
		return fail("%v", err)
	}
	log.Debugf("write pass took %s", time.Since(started).Round(time.Millisecond))
	var ms runtime.MemStats
	runtime.ReadMemStats(&ms)
	log.Debugf("memory obtained from the system: %.1f MB", float64(ms.Sys)/(1<<20))

	sum.Output, sum.DryRun, sum.Skipped = o.output, o.dryRun, skipped
	if o.dryRun {
		sum.Output = ""
		log.Infof("dry run: nothing written")
	} else {
		log.Infof("written: %s", o.output)
	}
	render := sum.WriteText
	if o.json {
		render = sum.WriteJSON
	}
	if err := render(stdout); err != nil {
		log.Warnf("%v", err)
		return exitFailed
	}
	if len(skipped) > 0 {
		return exitSkipped
	}
	return exitOK
}

// writeOutput merges into a temporary file beside output, checks the
// result, and renames it into place. On any error the temporary file
// is removed and an existing output file is left as it was.
func writeOutput(output string, files []*index.File, opts merge.Options) (sum *summary.Summary, err error) {
	tmp := output + ".tmp"
	fh, err := os.Create(tmp)
	if err != nil {
		return nil, err
	}
	defer func() {
		if err != nil {
			fh.Close()
			os.Remove(tmp)
		}
	}()

	w := bufio.NewWriterSize(fh, 1<<20)
	if sum, err = merge.Write(w, files, opts); err != nil {
		return nil, err
	}
	if err = w.Flush(); err != nil {
		return nil, err
	}
	if err = fh.Sync(); err != nil {
		return nil, err
	}
	if err = fh.Close(); err != nil {
		return nil, err
	}
	if err = verify(tmp, sum); err != nil {
		return nil, err
	}
	if err = os.Rename(tmp, output); err != nil {
		return nil, err
	}
	return sum, nil
}

// verify reads the written file back and checks that it is well-formed
// and holds the hosts and findings the summary says it does.
func verify(path string, sum *summary.Summary) error {
	f, err := index.Scan(path)
	if err != nil {
		return fmt.Errorf("output check failed: %w", err)
	}
	findings := 0
	for _, h := range f.Hosts {
		findings += h.Items
	}
	if len(f.Hosts) != sum.Hosts || findings != sum.Findings {
		return fmt.Errorf("output check failed: file holds %d host(s) and %d finding(s), expected %d and %d",
			len(f.Hosts), findings, sum.Hosts, sum.Findings)
	}
	return nil
}
````

````go
// nessknit must merge exactly as the Python script it replaces: the
// same hosts in the same order, each with the same properties and the
// same findings. The fixtures avoid the behaviours the design changed
// on purpose (a broken first file, hash collisions).
func TestParityWithPythonScript(t *testing.T) {
	python, err := exec.LookPath("python3")
	if err != nil {
		t.Skip("python3 not found")
	}
	root, err := filepath.Abs(filepath.Join("..", ".."))
	if err != nil {
		t.Fatal(err)
	}
	script := filepath.Join(root, "testdata", "reference", "nessus_merger_v4.py")
	fixtures, err := filepath.Glob(filepath.Join(root, "testdata", "parity", "*.nessus"))
	if err != nil || len(fixtures) < 3 {
		t.Fatalf("fixtures: %v, %v", fixtures, err)
	}

	// Each tool gets its own copy of the fixtures, because the Python
	// script writes its output into the directory it reads.
	pyDir, goDir := t.TempDir(), t.TempDir()
	for _, f := range fixtures {
		data, err := os.ReadFile(f)
		if err != nil {
			t.Fatal(err)
		}
		nt.Write(t, pyDir, filepath.Base(f), string(data))
		nt.Write(t, goDir, filepath.Base(f), string(data))
	}

	if out, err := exec.Command(python, script, "Combined.nessus", pyDir).CombinedOutput(); err != nil {
		t.Fatalf("python script failed: %v\n%s", err, out)
	}
	nessknit(t, goDir).wantCode(t, 0)

	want := nt.Parse(t, filepath.Join(pyDir, "Combined.nessus"))
	got := nt.Parse(t, filepath.Join(goDir, "Combined.nessus"))

	if got.Policy != want.Policy || got.ReportName != want.ReportName {
		t.Errorf("policy %q / report %q, want %q / %q", got.Policy, got.ReportName, want.Policy, want.ReportName)
	}
	if len(got.Hosts) != len(want.Hosts) {
		t.Fatalf("%d hosts, want %d", len(got.Hosts), len(want.Hosts))
	}
	if len(want.Hosts) != 4 {
		t.Fatalf("the fixtures should merge to 4 hosts, the Python script gave %d", len(want.Hosts))
	}
	for i, w := range want.Hosts {
		g := got.Hosts[i]
		if g.Name != w.Name {
			t.Errorf("host %d is %q, want %q", i, g.Name, w.Name)
			continue
		}
		if !reflect.DeepEqual(g.Tags, w.Tags) {
			t.Errorf("%s properties:\n got %v\nwant %v", w.Name, g.Tags, w.Tags)
		}
		if !reflect.DeepEqual(g.Items, w.Items) {
			t.Errorf("%s findings:\n got %v\nwant %v", w.Name, g.Items, w.Items)
		}
	}
}
````

````markdown
# nessknit

Merge several Nessus scan exports (`.nessus` files) into one.

`nessknit` is for the case where one engagement ends up as many scans:
separate subnets, separate scanners, or the same hosts scanned again
later. It produces a single `.nessus` file that imports back into
Nessus and loads into reporting tools, with duplicate findings removed.

It reads the inputs as streams, so memory use stays flat however large
the scans are.

Not affiliated with or endorsed by Tenable. Nessus is a trademark of
Tenable, Inc.

## Install

With Go 1.24 or later:

```
go install github.com/ich1go45/nessknit/cmd/nessknit@latest
```

## Usage

```
nessknit [flags] <path>...
```

Each path is a `.nessus` file or a directory of them (not searched
recursively). With no path, the current directory is used.

```
# Merge every .nessus file in the current directory into Combined.nessus
nessknit

# Merge a directory, choosing the output file and report name
nessknit -o acme-internal.nessus --name "ACME internal" scans/

# Merge named files; the first one supplies the scan policy
nessknit -o merged.nessus dmz.nessus servers.nessus workstations.nessus

# See what a merge would produce without writing anything
nessknit --dry-run scans/

# Machine-readable summary
nessknit --json -q scans/ > summary.json
```

| Flag | Meaning | Default |
|---|---|---|
| `-o`, `--output` | Output file | `Combined.nessus` |
| `--name` | Report name in the merged file | `Combined Report` |
| `--dry-run` | Run the merge and print the summary, write nothing | off |
| `--json` | Print the summary as JSON | off |
| `-q`, `--quiet` | Suppress progress output | off |
| `-d`, `--debug` | Print detailed diagnostics | off |
| `--version` | Print the version | |
| `-h`, `--help` | Print help | |

Progress, warnings and diagnostics go to stderr. The summary goes to
stdout.

### Exit codes

| Code | Meaning |
|---|---|
| `0` | Merged cleanly |
| `1` | Failed; nothing written |
| `2` | Bad usage |
| `3` | Merged and written, but at least one input file was skipped |

Check for `3` in scripts: it means a scan is missing from the result.

## How files are merged

- **Order.** Files are merged in the order given. Files from a
  directory are taken in name order.
- **Policy.** The first usable file supplies the scan policy and the
  report settings. The other files' policies are dropped.
- **Hosts.** Hosts are matched by their exact name in the file. A host
  scanned once by IP address and once by hostname stays as two hosts.
- **Findings.** When a host appears more than once, its findings are
  combined. A finding is a duplicate, and dropped, if it has the same
  plugin, port, protocol and plugin output as one already kept. The
  same plugin with different output is kept as a separate finding.
- **Host properties.** Combined across all scans of the host. Where two
  scans disagree on a property, the earlier file wins.
- **Scan information.** Plugin 19506 (Nessus Scan Information) is kept
  only from the first scan of each host.
- **Rescans.** Findings are never removed. A vulnerability fixed
  between two scans still appears in the merged file, because the
  earlier scan reported it.

The output file is never read as an input, so running `nessknit` twice
in the same directory is safe.

### Files that cannot be merged

An input is skipped, with a warning, if it is not well-formed XML, is
not UTF-8, or is not a Nessus v2 export. `nessknit` does not try to
repair broken files. The remaining files are still merged and the exit
code is `3`.

The merged file is written to a temporary file, checked, and only then
moved into place. If anything fails, an existing output file is left
untouched.
````
